Toy data

Two generators produce frames with a known answer, for exploring what the maps look like before trusting them on real output. They live with the tests, in test/synthetic.jl, and load with include(joinpath(pkgdir(SpaceTimeCorrelations), "test", "synthetic.jl")).

Tierbrief

noiseFrames gives the null case. bumpFrames gives Gaussian bumps of expression that can drift relative to the agents while the agents themselves flow.

Tierfull

In bumpFrames each agent has a material coordinate ξ (where it started), and its value is a periodic field of Gaussian bumps of width σ, evaluated at ξ - relative_velocity·t. So the value is carried by the agent, and relative_velocity is how fast the pattern moves through the agents. The agents' positions advance by flow each frame; flow can be a function of position for nonuniform motion.

The known answers:

Tierfull

Why exp(-r² / 4σ²)? Bumps placed at random are a shot-noise field; its covariance is the overlap of two Gaussians of width σ a distance r apart, which is a Gaussian of width √2·σ. The decay is wider than a single bump, which is worth remembering when reading a cluster size off a real map.

Turnover, as generated here, gives a newcomer the place of the agent it replaces. The values do not change; only the IDs do, which isolates the effect of losing base agents.
