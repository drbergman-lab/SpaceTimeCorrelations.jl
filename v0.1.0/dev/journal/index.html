2026-10-08 — Per-frame z-scoring

Decided: z-score each frame separately, with the population standard deviation. Why: a frame-wide shift in expression (the whole sheet brightening over a run) is a trend, not a spatial correlation, and pooled normalisation would read it as long-range positive correlation at every lag. The population SD makes the self-pair term average exactly 1, so the zero bin at lag 0 reads 1 for uncorrelated values. Open: whether pooled normalisation should be an option, for cases where the frame-to-frame change in level is itself the signal.

2026-10-08 — Directed displacement, not symmetrised

Decided: keep d = x_j(t+Δt) - b_i with its sign, and return the full plane. Rejected: folding d and -d together, which halves the noise but erases the direction of travel, the main thing the lagged maps are for.

2026-10-08 — Square grid, searched to its corners

Decided: search the circumscribing radius and keep the square grid whole. Rejected: searching a disk of radius rmax, which leaves the corner bins permanently empty and makes "empty" mean two different things; and defining the output as the disk, which needs a mask to explain every plot. The extra search area costs a factor of about 4/π in pairs considered.

2026-10-08 — No thresholding of values

Decided: correlate the continuous value; never threshold it into categories. Rejected: thresholding expression and running a pair correlation function or Ripley's K on the "high" agents. The cutoff is arbitrary, the result moves with it, and the graded signal that distinguishes a weak patch from a strong one is thrown away.

2026-10-08 — IDs used only for the base agent

Decided: the tissue frame uses agent i's own later position as the base point, and matches partners by position at t + Δt only. Rejected: estimating one global shift per frame pair (mean agent displacement) and subtracting it. That is exact only for uniform flow; under shear or opposing flows it leaves a spurious drift that looks like pattern motion. Also rejected: requiring partners to be tracked too, which would drop every newborn agent and adds nothing, since the partner's earlier position plays no role in d.

2026-10-08 — Tables come one per frame

Decided: the table method takes a vector of per-frame tables. Rejected: a single long table with a time column. It would have to infer frame spacing from the time values, and an empty frame (no agents) cannot appear in it, silently shifting every later lag by one. Per-frame tables are also what a loop over saved snapshots produces.

2026-10-08 — PhysiCell support as extensions, dead cells out by default

Decided: PhysiCellOutput and PhysiCellModelManager are weak dependencies, each reached through a thin extension over the array method, with a cell_types filter. Decided: exclude dead cells by default, matching PhysiCellOutput's cellDataSequence. In the first test run (a cortex model) every rgc cell was marked dead for 51 frames before removal; including them would correlate the values of cells that have stopped signalling. Rejected: testing the PCMM extension here. PCMM's dependencies conflict with the GeoStatsFunctions cross-check (Optim 1 against Optim 2), and the extension is one line.
